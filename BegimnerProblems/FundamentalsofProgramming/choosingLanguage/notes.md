# Programming Languages & Choosing a Path

## The Right Order

```
Problem → Algorithm → Pseudocode → Code
```

> Language doesn't fix bad logic!

---

## Syntax vs Semantics vs Correctness

| Term | Question |
|------|----------|
| **Syntax** | Is it written correctly? |
| **Semantics** | What does it mean? |
| **Correctness** | Does it solve the problem? |

## Same Logic, Different Languages

**Problem:** Even or Odd?

**Java:**
```java
if (n % 2 == 0) {
    System.out.println("Even");
} else {
    System.out.println("Odd");
}
```

**Python:**
```python
if n % 2 == 0:
    print("Even")
else:
    print("Odd")
```

**C++:**
```cpp
if (n % 2 == 0) {
    cout << "Even";
} else {
    cout << "Odd";
}
```

> Same logic. Different syntax.
