# DSA Is Language-Independent

## Main Idea
DSA = Problem solving, not language.  
You can use **Go**, C++, Java, Python — doesn't matter.

---

## Steps to Solve Any Problem

1. **Understand** the problem
2. **Think** of steps (logic)
3. **Write** code in Go

---

## Example: Even or Odd

**Logic:** If `n % 2 == 0` → Even, else Odd

```go
if n % 2 == 0 {
    fmt.Println("Even")
} else {
    fmt.Println("Odd")
}
```

---

## Remember
> Logic first. Language is just a tool.
