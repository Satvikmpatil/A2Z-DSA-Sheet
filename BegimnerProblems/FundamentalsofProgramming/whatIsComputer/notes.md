# Programming and Computers

## What is Programming?
Giving **step-by-step instructions** to a computer.

> Like making tea: boil water → add tea → add milk → filter. Order matters!

---

## What is a Computer?
A machine that follows instructions. Fast but **no common sense** — does exactly what you tell it.

---

## Hardware vs Software

| Hardware | Software |
|----------|----------|
| Physical parts | Programs |
| CPU, RAM, Screen | Java, Browser, Apps |

---

## Key Parts

- **Storage** — Saves files (permanent)
- **RAM** — Fast temporary memory (lost when off)
- **CPU** — Runs instructions (the processor)
- **OS** — Manages everything (Windows, macOS, Linux)

---

## Your First Java Program

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

## Remember
> Computer = follows instructions. You = write the instructions.
