# How to Think Like a Programmer

## Main Idea
**Understand first, code later.**

---

## Steps to Solve Any Problem

1. **Read** — What is the problem?
2. **Input** — What is given?
3. **Output** — What to produce?
4. **Logic** — What are the steps?
5. **Code** — Write in Go

---

## Example: Find Largest of 3 Numbers

```go
largest := a
if b > largest {
    largest = b
}
if c > largest {
    largest = c
}
fmt.Println(largest)
```

---

## 4 Thinking Skills

| Skill | Meaning |
|-------|---------|
| **Decomposition** | Break big problem into small parts |
| **Pattern** | Reuse similar logic |
| **Abstraction** | Focus on what matters |
| **Algorithm** | Steps in correct order |

---

## Common Mistakes

- Coding before understanding
- Testing only given examples
- Ignoring edge cases (0, negative, equal values)

---

## Remember
> Syntax = how to write. Logic = what to write.
