# A2Z-DSA-Sheet

A2Z DSA Sheet with optimized solutions in **Java**, notes, patterns, and complexity analysis.

## Structure

- **BegimnerProblems/** - Beginner level problems
  - `BasicMaths/` - Math problems (digit count, reverse, palindrome, factorial, GCD, LCM, etc.)
  - `Patterns/` - Pattern printing problems (22 patterns)
  - `BasicHashing/` - Hashing problems (frequency, most occurring element)
  - `BasicArrays/` - Array problems (sum, reverse, sorted check)
  - `FundamentalsofProgramming/` - Programming concepts and notes
  - `LanguageBasics/` - Java learning resources
  - `StandardLibrariesCollections/` - Java Collections guide

## Language

All solutions are implemented in **Java**.
